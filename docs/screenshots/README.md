# 데모 스크린샷

Streamlit 데모 화면을 다음 파일명으로 저장합니다.

| 파일명 | 권장 화면 | 권장 비율 |
|---|---|---:|
| `demo-overview.png` | 제목, Event 선택, 지도까지 포함한 전체 화면 | 16:9 |
| `demo-weather.png` | 현장 참고 기상정보 카드 | 2:1 |
| `demo-documents.png` | 상황 브리핑 또는 현장점검 지시서 | 4:3 |
| `demo-followup.png` | 사후 결과 입력 및 결과보고서 | 4:3 |

## 캡처 권장사항

- 브라우저 배율은 90~100%로 맞춥니다.
- API 키, 사용자 정보, 브라우저 북마크는 화면에 포함하지 않습니다.
- 네 장의 이미지 너비와 배율을 가능한 한 통일합니다.
- 전체 화면은 실제 민원 위치나 개인정보가 노출되지 않는 데모 Event로 촬영합니다.
- 이미지를 추가한 후 루트 `README.md`의 `데모 화면` 섹션에 표시된 HTML 주석을 해제합니다.
